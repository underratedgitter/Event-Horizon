# 0002: Zero-Dependency HTML5 Canvas 2D and Procedural Web Audio

Heavy web frontend frameworks and bundlers introduce friction, complex build steps, and maintenance overhead for canvas physics sandboxes. We decided to build the sandbox using standard native ES modules, HTML5 Canvas 2D with subpixel retina scaling, and the Web Audio API for procedural cosmic sound effects, enabling instant zero-install browser execution and consistent 60+ FPS performance across devices.
